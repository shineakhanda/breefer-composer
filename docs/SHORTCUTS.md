# Keyboard shortcuts

Press **F1** in the app for this list. Shortcuts follow Premiere Pro's defaults.
Navigation keys (arrows, Home/End, Space, Delete) go to the focused list or text field when
you are typing in one, and to the editor otherwise.

## Tools (timeline)

| Key | Tool |
|---|---|
| `V` | Selection |
| `A` | Track Select Forward (`Shift` = this track only) |
| `B` | Ripple Edit |
| `N` | Rolling Edit |
| `R` | Rate Stretch |
| `C` | Razor (`Shift` = cut every track) |
| `Y` | Slip |
| `U` | Slide |
| `H` | Hand (middle mouse button also pans) |
| `Z` | Zoom (`Alt` = zoom out) |
| `T` | New title at the playhead |

## Playback and navigation

| Key | Action |
|---|---|
| `Space` | Play / stop |
| `J` `K` `L` | Shuttle back / stop / forward (press again to double speed, up to 8×) |
| `←` `→` | Step one frame (`Shift` = 5 frames) |
| `↑` `↓` | Previous / next edit point on targeted tracks |
| `Home` `End` | Go to sequence start / end |
| `Shift+M` / `Ctrl+Shift+M` | Next / previous marker |
| `Shift+I` / `Shift+O` | Go to In / Out |
| `F` | Match Frame: open the clip under the playhead in the Source monitor |
| `D` | Select the clip(s) under the playhead on targeted tracks |

## Marking and three-point editing

| Key | Action |
|---|---|
| `I` / `O` | Mark In / Out |
| `X` | Mark Clip |
| `Ctrl+Shift+X` | Clear In and Out |
| `,` | Insert from Source |
| `.` | Overwrite from Source |
| `;` | Lift (remove In–Out, leave a gap) |
| `'` | Extract (remove In–Out and close the gap) |
| `M` | Add marker (`Ctrl+Alt+M` clears the one at the playhead) |

## Editing

| Key | Action |
|---|---|
| `Ctrl+K` | Add edit (split) at the playhead: selected clips, else targeted tracks |
| `Ctrl+Shift+K` | Add edit to all tracks |
| `Q` / `W` | Ripple-trim the previous / next edit to the playhead |
| `Delete` | Clear (leaves a gap) |
| `Shift+Delete` | Ripple delete (closes the gap) |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` | Copy, cut, paste at playhead |
| `Ctrl+Shift+V` | Paste insert |
| `Ctrl+Shift+/` | Duplicate |
| `Alt+←` `Alt+→` | Nudge selected clips one frame (`Shift` = 5) |
| `Alt+↑` `Alt+↓` | Move selected clips up / down a track |
| `+12` then `Enter` | Move selection (or playhead) by 12 frames; `-5` Enter moves back |
| `Ctrl+D` / `Ctrl+Shift+D` | Apply default video / audio transition |
| `Ctrl+R` | Speed/Duration |
| `Shift+E` | Enable / disable clip |
| `Ctrl+L` | Link / unlink selection |
| `Ctrl+Shift+L` | Toggle linked selection |
| `S` | Toggle snapping |
| `Ctrl+A` / `Ctrl+Shift+A` | Select all / deselect all |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo |

## Mouse modifiers on the timeline

| Gesture | Effect |
|---|---|
| `Ctrl` + drag a clip edge (Selection tool) | Ripple trim |
| `Ctrl` + drag a clip | Insert move (ripples later clips) |
| `Alt` + click a clip | Select only that side of a linked pair |
| `Alt` + drag a clip edge | Trim only that clip, not its linked partner |
| `Shift` / `Ctrl` + click | Add / toggle in selection |
| Drag a yellow line on an audio clip | Clip gain |
| Drag the bottom edge of a track header | Resize the track |
| `Ctrl` + wheel | Zoom time |
| `Shift` + wheel | Scroll horizontally |
| `Shift` while scrubbing the ruler | Snap to edit points |
